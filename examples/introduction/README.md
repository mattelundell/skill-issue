# Introduction

A short tour of the application, taken in it: two lessons of four short steps, in Swedish and English. It is a taste, not a course — each check is a single question that is hard to get wrong, and its explanation carries what is not obvious from the screen.

Its `subject.yaml` says `role: introduction`, so once both lessons have been gone through it leaves the start screen, and its questions are never part of a review of every subject.

Anything it says about the screen is checked against the screen; a change to the interface that it describes changes it too.
