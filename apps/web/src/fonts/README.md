# Fonts

The two typefaces the design uses, served by the application itself so that every installation shows them without fetching anything from elsewhere. Both are licensed under the SIL Open Font License 1.1, whose text is beside each.

| File | Typeface | Taken from |
|---|---|---|
| `AtkinsonHyperlegibleNext.ttf`, `AtkinsonHyperlegibleNext-Italic.ttf` | Atkinson Hyperlegible Next, variable weight | `ofl/atkinsonhyperlegiblenext/` in github.com/google/fonts |
| `Newsreader.ttf` | Newsreader, variable weight and optical size, upright only | `ofl/newsreader/` in github.com/google/fonts |
